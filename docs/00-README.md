## Status labels used in every file
- **Built**: exists in the repo and was type-checked or tested.
- **Prototype**: shown in the React UI with mock data, not wired to the backend.
- **Proposed**: a design intention, not built.
- **Unverified**: no source yet. Fill in before sharing.

No market, pricing, competitor or traction numbers are included because none are sourced.
Items about security, cost or people should be reviewed by a human before the pack is shared.
